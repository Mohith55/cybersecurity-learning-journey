# Day 21 – OWASP ZAP (Automated Vulnerability Scanning)

## Objective
To understand how automated vulnerability scanners are used
to quickly map and assess web applications.

## What is OWASP ZAP?
OWASP ZAP (Zed Attack Proxy) is an open-source web application
security scanner used for automated and manual testing.

## Key Capabilities
- Automated vulnerability scanning
- Web crawling and spidering
- Attack surface mapping
- Identification of common security issues

## Attacker vs Defender Perspective
- Attackers use scanners to quickly map targets
- Defenders use scanners for proactive security testing

## Key Learning
Automation allows rapid discovery of vulnerabilities.
Regular scanning is essential for secure applications.
