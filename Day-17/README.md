# Day 17 – Burp Suite Basics

## Objective
To understand how web application traffic can be intercepted,
analyzed, and tested using Burp Suite.

## What is Burp Suite?
Burp Suite is a web security testing platform that allows
interception and manipulation of HTTP/HTTPS traffic.

## Core Concepts Learned
- Proxy-based interception
- HTTP request and response analysis
- Parameter manipulation
- Understanding client-server communication

## Why Burp Suite is Important
- Reveals hidden application behavior
- Helps identify authentication and validation flaws
- Used by both attackers and defenders
- Essential for application security testing

## Key Learning
Web vulnerabilities often exist in how requests are processed,
not just in visible UI elements.
