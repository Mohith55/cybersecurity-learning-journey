# Day 14 – Mutillidae Practice

## Objective
To understand real-world web vulnerabilities by simulating attacks
on a deliberately vulnerable web application.

## What is Mutillidae?
Mutillidae is an intentionally insecure web application designed
to demonstrate OWASP Top 10 vulnerabilities in realistic scenarios.

## Vulnerabilities Practiced
- SQL Injection
- Cross-Site Scripting (XSS)
- Authentication flaws
- Input validation issues
- Session management weaknesses

## Key Learning
- Many real websites fail due to poor maintenance
- Vulnerabilities are often basic and predictable
- Secure coding and patching prevent most attacks

## Takeaway
Web security failures usually result from ignored fundamentals,
not advanced exploitation.
