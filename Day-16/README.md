# Day 16 – OWASP Top 10

## Objective
To understand the most critical web application security risks
that repeatedly cause real-world data breaches.

## What is OWASP Top 10?
The OWASP Top 10 is a regularly updated list of the most
common and impactful web application vulnerabilities.

## Why It Is Important
- Represents real-world attack patterns
- Used as a security baseline worldwide
- Helps prioritize security efforts
- Relevant to developers and security professionals

## Common Risk Categories
- Broken Access Control
- Injection
- Insecure Authentication
- Security Misconfiguration
- Vulnerable and Outdated Components

## Key Learning
Most breaches occur due to known issues being left unpatched,
not because of advanced zero-day attacks.

## Takeaway
Understanding and mitigating OWASP Top 10 risks
significantly improves application security.
