# Day 26 – Log Analysis & Incident Response

## Objective
To understand how log analysis supports effective
incident detection, investigation, and response.

## Why Logs Are Critical
- Provide evidence of activity
- Enable attack timeline reconstruction
- Support detection and containment
- Aid post-incident analysis

## Common Log Sources
- Authentication logs
- Web server logs
- System and application logs
- Network and firewall logs

## Incident Response Phases
1. Detection
2. Analysis
3. Containment
4. Eradication
5. Recovery
6. Lessons Learned

## Key Learning
Incident response depends on visibility.
Logs turn incidents into actionable intelligence.
