 – SOC Workflow & Alert Triage

## Objective
To understand how Security Operations Centers (SOC)
handle alerts and respond to security incidents.

## What is a SOC?
A SOC monitors, detects, investigates, and responds
to cybersecurity threats in real time.

## Alert Triage
Alert triage involves:
- Reviewing alerts
- Assessing severity and impact
- Filtering false positives
- Escalating genuine threats

## Typical SOC Workflow
1. Alert generation (SIEM / EDR)
2. Triage and validation
3. Investigation
4. Containment and response
5. Documentation and closure

## Key Learning
Not all alerts are incidents.
Effective triage ensures focus on real threats.

## Takeaway
SOC efficiency depends on prioritization,
analysis skills, and structured response processes.
