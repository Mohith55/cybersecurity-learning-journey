# Day 20 – Password Attacks & Brute-Forcing

## Objective
To understand how weak authentication mechanisms are exploited
through password brute-forcing techniques.

## What Are Password Attacks?
Password attacks involve guessing or brute-forcing credentials
to gain unauthorized access to systems.

## Why They Work
- Weak or reused passwords
- No rate limiting
- No account lockout
- Default credentials

## Attacker vs Defender Perspective
- Attackers brute-force authentication services
- Defenders test systems to identify weaknesses

## Key Learning
Authentication is one of the most targeted components in security.
Weak passwords undermine all other protections.

## Takeaway
Strong passwords, rate limiting, account lockout,
and multi-factor authentication are essential defenses.
