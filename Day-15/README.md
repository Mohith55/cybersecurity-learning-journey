# Day 15 – OWASP Juice Shop

## Objective
To understand how modern web applications fail due to logic flaws,
insecure authentication, and improper validation.

## What is OWASP Juice Shop?
OWASP Juice Shop is an intentionally vulnerable modern web application
that demonstrates real-world application security issues.

## Vulnerabilities Explored
- Business logic flaws
- Insecure authentication
- Improper input validation
- Design-level security weaknesses

## Key Learning
- Modern attacks often exploit logic, not just code bugs
- Authentication flows must be carefully designed
- Validation and trust boundaries are critical
- Secure design is as important as secure coding

## Takeaway
Application security failures are usually design failures.
Understanding logic flaws is essential for modern cybersecurity.
