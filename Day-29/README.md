# Day 29 – SOC Tools Overview

## Objective
To understand the tools used in a Security Operations Center
and how they support threat detection and incident response.

## What is a SOC?
A Security Operations Center monitors, detects, investigates,
and responds to cybersecurity threats.

## Key SOC Tools
- SIEM: Log collection and event correlation
- EDR/XDR: Endpoint detection and response
- SOAR: Security automation and orchestration
- IDS/IPS: Network intrusion detection and prevention

## Why SOC Tools Are Important
- Provide centralized visibility
- Reduce alert fatigue through correlation
- Enable faster incident response
- Support security analysts at scale

## Key Learning
SOC effectiveness depends on tools, processes, and skilled analysts.

## Takeaway
SOC tools turn security data into actionable intelligence.
