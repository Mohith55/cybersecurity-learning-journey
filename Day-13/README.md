# Day 13 – DVWA Practice

## Objective
To understand how common web vulnerabilities arise due to poor coding practices
by practicing in a controlled lab environment.

## What is DVWA?
DVWA (Damn Vulnerable Web Application) is an intentionally vulnerable
web application designed for learning and testing security flaws.

## Vulnerabilities Explored
- SQL Injection
- Cross-Site Scripting (XSS)
- Command Injection
- Authentication Issues

## Key Learning
- Most vulnerabilities are caused by insecure coding
- Proper input validation is critical
- Secure coding reduces attack surface
- Practice must always be done in legal environments

## Takeaway
Security starts at the code level.
Understanding vulnerabilities helps prevent them.
