# Day 12 – Nmap Scanning

## Objective
To understand how network scanning is performed using Nmap
and why it is critical in cybersecurity.

## What is Nmap?
Nmap (Network Mapper) is an open-source tool used to:
- Discover hosts on a network
- Scan open ports
- Identify services and versions
- Perform OS fingerprinting

## Why Scanning is Important
- Reveals exposed services
- Helps reduce attack surface
- Used in both offense and defense
- Forms the foundation of security assessments

## Attacker vs Defender Perspective
- Attackers use scanning for reconnaissance
- Defenders use scanning for audits and hardening

## Key Learning
Nmap does not exploit systems.
It provides visibility into how a network appears from the outside.
