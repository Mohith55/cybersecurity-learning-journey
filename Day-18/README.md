# Day 18 – WPScan (WordPress Vulnerability Scanning)

## Objective
To understand how common WordPress vulnerabilities are identified
and exploited using automated scanning tools.

## What is WPScan?
WPScan is a WordPress-specific security scanner used to detect:
- Vulnerable WordPress core versions
- Outdated or insecure plugins and themes
- Misconfigurations and exposed endpoints

## Why WordPress is Frequently Attacked
- Large global usage
- Heavy reliance on third-party plugins
- Poor update and maintenance practices

## Attacker vs Defender Perspective
- Attackers use WPScan for reconnaissance
- Defenders use WPScan for security audits and hardening

## Key Learning
Most WordPress compromises result from known vulnerabilities
being left unpatched.

## Takeaway
Security maintenance is as important as secure development.
