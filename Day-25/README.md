# Day 25 – File Systems (Windows, Linux & Android)

## Objective
To understand how different operating systems organize files
and why this knowledge is critical for malware analysis.

## Windows File System
- Common malware locations:
  - C:\Users\
  - AppData\Roaming
  - Startup folders
- Persistence through registry and startup paths

## Linux File System
- Key directories:
  - /etc (configuration)
  - /bin, /usr/bin (binaries)
  - /tmp (temporary files)
- Malware abuses permissions and cron jobs

## Android File System
- /data/data/ for app data
- /system for OS components
- Malware hides inside application directories

## Key Learning
Malware follows OS-specific file system logic.
Understanding file paths speeds up analysis and detection.

## Takeaway
File system knowledge is foundational for malware analysis
and digital forensics.
