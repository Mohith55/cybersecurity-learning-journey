# Day 22 – Client-Side vs Server-Side Security

## Objective
To understand the difference between client-side and server-side
security using JavaScript and PHP.

## Client-Side (JavaScript)
- Runs in the user's browser
- Handles UI and basic validation
- Can be modified or bypassed by attackers
- Should never be trusted for security decisions

## Server-Side (PHP)
- Runs on the server
- Enforces authentication and authorization
- Handles database operations
- Cannot be modified by the client

## Common Security Mistake
Relying only on client-side validation for security.
Attackers can bypass frontend controls easily.

## Key Learning
Client-side checks improve usability.
Server-side checks provide real security.
