# Day 28 – Memory Forensics Basics

## Objective
To understand how volatile memory (RAM) analysis
supports malware detection and incident response.

## What is Memory Forensics?
Memory forensics involves analyzing RAM to extract
runtime information from a live or captured system.

## Why Memory Analysis is Important
- Detects fileless malware
- Reveals injected processes
- Shows active network connections
- Captures encryption keys and artifacts

## Key Learning
Some of the most important evidence exists only in memory.
Disk analysis alone is not sufficient for modern attacks.

## Takeaway
Memory forensics provides real-time visibility
into what a system is actually doing.
