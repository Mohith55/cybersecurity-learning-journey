# Day 19 – Directory Brute-Forcing

## Objective
To understand how hidden directories and files can be discovered
due to web server misconfigurations.

## What is Directory Brute-Forcing?
A technique used to enumerate directories and files
by testing common and known paths on a web server.

## What Can Be Exposed
- Hidden admin panels
- Configuration files
- Backup and test directories
- Sensitive resources

## Why It Is Dangerous
- Exposes sensitive application components
- Often requires no authentication
- Exploited in real-world attacks

## Key Learning
Security through obscurity is ineffective.
Proper access control and server hardening are essential.

## Takeaway
Misconfigurations are one of the most common causes of web breaches.
