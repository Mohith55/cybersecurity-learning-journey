# Day 32 – Threat Hunting Fundamentals

## Objective
To understand proactive threat detection
through structured threat hunting techniques.

## What is Threat Hunting?
Threat hunting is a proactive security practice
focused on identifying hidden or unknown threats.

## Why It Matters
- Not all attacks trigger alerts
- Advanced attackers evade signatures
- Reduces attacker dwell time
- Improves detection capabilities

## Threat Hunting Process
1. Form a hypothesis
2. Collect relevant data
3. Investigate anomalies
4. Respond to findings
5. Improve detections

## Key Learning
Threat hunting is behavior-focused and proactive.
It complements SOC alert-based monitoring.
