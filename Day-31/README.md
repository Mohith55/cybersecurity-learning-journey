# Day 31 – Privilege Escalation Fundamentals

## Objective
To understand how attackers escalate privileges
and why this step is critical in real-world attacks.

## What is Privilege Escalation?
Privilege escalation occurs when a user gains
permissions beyond what was originally intended.

## Why It Is Dangerous
- Enables full system control
- Bypasses security restrictions
- Allows persistence and lateral movement

## Common Causes
- Misconfigured permissions
- Weak sudo / admin rules
- Vulnerable services
- Unpatched operating systems

## Key Learning
Initial access alone rarely causes damage.
Privilege escalation determines the real impact.

Applying least privilege and secure configuration
